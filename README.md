# Aznora IDE

### Code anywhere. Learn anywhere. Build anywhere.

Aznora is a cross-platform IDE designed to make programming accessible on **any device**.

Today, development is often tied to having a proper computer. A student might understand programming but only have a phone or Chromebook. A developer may be away from their PC. A teacher may need to quickly demonstrate or test code without setting up a full development environment.

**Aznora aims to change that.**

With Aznora, the same development environment can be available on:

**Windows • macOS • Linux • ChromeOS • Android • iOS/iPadOS • Web**

## For Students

Aznora can make learning programming much easier.

A student doesn't need to wait until they have access to a computer just to practice.

They can:

* Write and run code from a phone or tablet
* Practice programming between classes
* Work on university assignments from a Chromebook
* Access their projects from different devices
* Connect directly to GitHub
* Continue a project without setting everything up again
* Learn multiple programming languages in one place

A student could start an assignment on a university computer, continue it on a Chromebook, and make a quick correction from their phone while travelling.

## For Teachers

Aznora can also simplify teaching.

Teachers can:

* Demonstrate code directly during class
* Open and test student projects
* Share projects through GitHub
* Prepare programming exercises without configuring multiple computers
* Work from a laptop, tablet, or classroom computer
* Keep teaching materials and development projects accessible across devices

Instead of worrying about whether a classroom computer has the correct compiler, editor, or development environment, Aznora is designed to make the environment itself portable.

## For Developers

Aznora is designed for developers who don't always want to carry their main machine everywhere.

Start working on a project on your PC.

Continue on a Chromebook.

Make a quick change from your phone.

Return to your desktop and keep going.

The long-term vision is for your **workspace to follow you**, rather than forcing you to stay attached to one device.

## One IDE. Every Device.

Aznora is being built around one simple idea:

> **Your ability to create software shouldn't depend on which device is in front of you.**

A powerful computer should give you more performance, but even a small device should still let you access your projects, learn, experiment, and contribute.

Aznora is being built from scratch with that vision in mind.

**Free. Cross-platform. Built for everyone who codes.**
